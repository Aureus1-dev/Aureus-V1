# Experience Canon

Status: Permanent

---

# Purpose

The Experience Canon is the constitutional body of documents governing every member-facing experience within Aureus.

It defines how Aureus should feel, behave, communicate, evolve, and be implemented.

The Experience Canon protects the member experience across decades, regardless of changing technology, teams, frameworks, or design trends.

# Guiding Principle

Every future experience should answer one question:

> Does this responsibly help someone flourish?

If yes:

Strengthen it.

If not:

Remove it.
