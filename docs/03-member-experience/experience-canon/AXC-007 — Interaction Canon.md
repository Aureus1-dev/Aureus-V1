# Purpose

This document establishes the permanent principles governing every interaction between members and Aureus.

Every click, tap, swipe, voice command, keyboard input, gesture, and response should reinforce stewardship.

Interactions should feel effortless, understandable, respectful, and deeply human.

---

# First Principle

Interaction should reduce effort.

Never increase it.

Members should spend their attention solving their problems.

Not learning software.

---

# Stewardship Before Interface

Members interact with a steward.

Not an application.

The interface exists only to support stewardship.

Whenever the interface becomes the focus instead of the member's progress, redesign it.

---

# One Clear Next Step

Every screen should present one primary action.

Members should never wonder:

"What am I supposed to do next?"

The next meaningful step should always be obvious.

---

# Progressive Disclosure

Reveal complexity only when it becomes useful.

Never overwhelm members with options they do not yet need.

Simple first.

Powerful when necessary.

---

# Consistency

Interactions should behave consistently throughout Aureus.

Buttons behave consistently.

Gestures behave consistently.

Navigation behaves consistently.

Members should build confidence through familiarity.

---

# Immediate Feedback

Every interaction should receive an immediate response.

Members should always know:

- Their action was received.
- What is happening now.
- What will happen next.

Uncertainty reduces trust.

---

# Forgiveness

Mistakes should be easy to recover from.

Provide:

- Undo whenever responsibly possible.
- Clear confirmations for irreversible actions.
- Helpful recovery paths.

Members should feel safe exploring Aureus.

---

# Voice and Touch

Voice and touch are equal citizens.

Members may speak.

Members may type.

Members may navigate visually.

No interaction method should feel secondary.

---

# The Aureus Mark

The Aureus Mark is the member's primary point of interaction.

It represents stewardship.

It may:

- Listen.
- Guide.
- Navigate.
- Confirm.
- Focus attention.

It should never become decorative.

---

# Navigation

Members should always know:

- Where they are.
- How they arrived.
- Where they can go next.

Navigation should feel like walking through a meaningful place.

Not traversing software menus.

---

# Respect for Attention

Never interrupt unnecessarily.

Never require unnecessary confirmations.

Never request unnecessary input.

Respect attention as a finite resource.

---

# Accessibility

Every interaction must remain accessible regardless of:

- Physical ability.
- Vision.
- Hearing.
- Language.
- Technical confidence.
- Cognitive differences.

Accessibility is a constitutional requirement.

---

# Performance

Interactions should feel immediate.

Responsiveness communicates competence.

Waiting without explanation reduces trust.

Whenever delays occur, communicate honestly.

---

# Success Criteria

The Interaction Canon succeeds when members naturally think:

"This feels easy."

"I always know what to do."

"I feel supported."

instead of thinking about the interface itself.

---

# Constitutional Reminder

Interactions exist to serve stewardship.

Never novelty.

Never engagement.

Never complexity.

Every interaction should make flourishing easier.

Helping people flourish.

Forever.
