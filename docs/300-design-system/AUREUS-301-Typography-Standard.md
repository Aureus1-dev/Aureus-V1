# AUREUS-301 — TYPOGRAPHY STANDARD

**Status:** Canon
**Authority:** Design Architecture

---

# PURPOSE

Typography is the voice of Aureus made visible.

Before a member understands the words, they experience how the words feel.

Typography should communicate warmth before authority.

Clarity before beauty.

Understanding before expression.

The purpose of this standard is to create one timeless typographic language that supports every member, every room, and every season of Aureus.

Typography exists to strengthen stewardship.

Never to draw attention to itself.

---

# PRIMARY RESPONSIBILITY

The Typography Standard exists to answer one question:

**"How should Aureus speak visually?"**

Its answer must always be:

**Clearly, calmly, warmly, and confidently.**

---

# RELATIONSHIP TO THE CANON

Typography derives its authority from:

Foundation.

Constitution.

Experience Canon.

Engineering Implementation Canon.

Design System Canon.

Typography exists to express those documents visually.

It may never contradict them.

---

# TYPOGRAPHY PHILOSOPHY

Typography should disappear behind understanding.

Members should never notice fonts.

Members should notice clarity.

Reading should feel effortless.

Long conversations should never become visually exhausting.

The visual rhythm should encourage reflection rather than speed.

---

# DESIGN PRINCIPLES

Typography should communicate:

Warmth.

Competence.

Calm.

Hope.

Trust.

Stability.

The visual tone should feel timeless rather than fashionable.

---

# TYPOGRAPHIC HIERARCHY

Every screen should contain a clear hierarchy.

Primary Heading

Introduces purpose.

Secondary Heading

Organizes understanding.

Body Text

Communicates information.

Supporting Text

Provides context.

Caption

Adds clarification without competing for attention.

Interactive Text

Clearly communicates available actions.

Hierarchy should remain consistent throughout Aureus.

---

# READABILITY

Typography should optimize:

Legibility.

Scanning.

Long-form reading.

Conversation.

Reflection.

Members should comfortably read long conversations without fatigue.

Line lengths should remain comfortable.

Spacing should encourage comprehension.

---

# EMPHASIS

Use emphasis sparingly.

Prefer:

Weight.

Spacing.

Position.

Avoid excessive use of:

Capital letters.

Bright colors.

Decorative styling.

Emphasis should guide attention.

Never create anxiety.

---

# RESPONSIVE TYPOGRAPHY

Typography should scale naturally across:

Desktop.

Tablet.

Mobile.

Large displays.

Printed materials.

The hierarchy should remain consistent regardless of screen size.

---

# ACCESSIBILITY

Typography shall support:

WCAG AA contrast.

Scalable text.

Screen readers.

High contrast mode.

Low vision accessibility.

Dyslexia-friendly spacing where appropriate.

Typography should remain understandable at 200% zoom.

Accessibility is mandatory.

---

# IMPLEMENTATION

The Design System shall define:

Font families.

Type scale.

Font weights.

Line heights.

Letter spacing.

Paragraph spacing.

Responsive scaling.

Semantic heading rules.

No implementation should introduce unauthorized font systems.

---

# PERFORMANCE

Typography should remain lightweight.

Prefer system performance.

Avoid unnecessary font downloads.

Minimize layout shift.

Typography should load gracefully.

Performance contributes directly to trust.

---

# TESTING REQUIREMENTS

Implementation shall verify:

Responsive scaling.

Heading hierarchy.

Contrast ratios.

Accessibility.

Zoom behavior.

Screen reader compatibility.

Performance budgets.

Cross-browser rendering.

---

# ACCEPTANCE CRITERIA

The Typography Standard is complete only when:

Reading feels effortless.

Hierarchy remains clear.

Accessibility passes.

Typography feels calm.

Long-form reading remains comfortable.

Performance remains excellent.

Typography strengthens the Aureus experience without becoming visually dominant.

---

# DEFINITION OF DONE

Typography implementation is complete only when:

- Canon requirements are satisfied.
- Typography tokens are defined.
- Accessibility passes.
- Responsive scaling is verified.
- Performance targets are achieved.
- Founder review confirms typography feels unmistakably Aureus.

---

# THE STANDARD

Typography succeeds when members stop noticing the text itself.

Instead, they simply understand.

The interface disappears.

The conversation remains.

---

# NON-NEGOTIABLES

- Clarity always comes before style.
- Readability always comes before decoration.
- Accessibility is mandatory.
- Typography should reduce cognitive effort.
- Consistency strengthens trust.
- Every word should visually communicate stewardship.
